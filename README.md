# Portfólio — Davi Afonso da Silva

Site de portfólio profissional para conseguir o primeiro estágio em desenvolvimento.

## Como usar

1. Abra o arquivo `index.html` no navegador.
2. Antes de publicar, edite em `index.html` o que estiver com marcação de exemplo:
   - Links reais do Demo e do GitHub na seção **Projetos**.
   - URL real do LinkedIn na seção **Contato**.
   - E-mail correto no link `mailto:`.

## Estrutura

```
portifolio2/
├── index.html       # Estrutura e textos
├── css/style.css    # Design, paleta e responsividade
└── js/script.js     # Menu mobile, scroll e animações
```

## Design usado

- **Tema:** escuro (clássico tech) — fundo `#0b1220`, cartões `#131d31`.
- **Acento:** ciano/teal `#5eead4` — transmite modernidade e energia.
- **Fontes:** Space Grotesk (títulos), Inter (texto), JetBrains Mono (código/detalhes).

## Como destacar o portfólio no LinkedIn e GitHub

### 1. Escreva um README de capa no GitHub
Não deixe o repositório vazio. No README de cada projeto, inclua com imagens/GIF:
**Problema → Solução → Tecnologias → Como rodar → Prints/Demo.**
Um GIF da gameplay do *Destruidor de Casas* no topo do README vale mais que mil palavras no currículo.

### 2. Transforme o projeto em uma "história de aprendizado"
No LinkedIn, publique o projeto com antes/depois: conte o que você **tentou, quebrou e consertou** durante o desenvolvimento. Recrutadores de estágio buscam gente que sabe **aprender**, não só código perfeito. Um post curto no dia em que você subiu o demo funciona muito bem.

### 3. Padronize perfil + link em tudo
- Foto profissional, headline com palavras-chave: *"Estudante de Front-end | HTML, CSS, JavaScript, React & Python"*.
- Na seção **Projetos** do LinkedIn, anexe o link do projeto com uma imagem destacada.
- Use o mesmo username (ex.: `destruidordecasas`) em GitHub, LinkedIn e no e-mail — isso passa organização e facilita a checagem do recrutador.
- Um bônus: um `portfolio` fixado no topo do GitHub e de 3 a 4 repositórios "pinados" relevantes.
